Deskripsi Repository : Platform ini berfungsi sebagai sarana penyimpanan dan manajemen arsip proyek secara daring melalui ekosistem GitHub. Repository ini digunakan untuk menyimpan, mengatur, dan menjelaskan berbagai file sehingga perubahan bisa diatur dengan baik dan diakses secara mudah.

Tujuan Repository :

1. Menyimpan file dan dokumentasi proyek secara terpusat.
2. Mengelola perubahan file menggunakan Git.
3. Mempermudah akses dan pengelolaan file melalui GitHub.
4. Menyediakan ruang penyimpanan proyek yang bisa dibagikan dan diakses melalui internet.

Dokumentasi Kegiatan Workshop : 

1. Prompt Engineering adalah metode untuk membuat instruksi yang tepat agar AI bisa memberikan jawaban yang benar, cocok, dan sesuai dengan apa yang diinginkan.

Struktur prompt yang baik terdiri dari:
- Role: menentukan peran AI.
- Task: menjelaskan tugas yang harus dilakukan.
- Context: memberikan informasi pendukung.
- Format: menentukan bentuk hasil yang diinginkan.

2. Pengenalan Git dan GitHub
- Git adalah sistem kontrol versi yang digunakan untuk mengelola perubahan pada file atau proyek.
- GitHub adalah situs web yang memungkinkan kita menyimpan repositori Git secara online dan mendukung kerja sama antar pengguna.

3. Konsep Dasar Git
Beberapa konsep penting yang dipelajari:
- Working Directory: tempat untuk mengerjakan dan mengubah file.
- Area staging berfungsi sebagai ruang penyiapan yang memungkinkan modifikasi dilakukan sebelum proses commit dilaksanakan.
- Repositori merupakan entitas yang berfungsi sebagai wadah penyimpanan Git untuk mendokumentasikan dan mengelola seluruh riwayat evolusi sebuah proyek.
- Commit merupakan mekanisme untuk menabadkan modifikasi yang telah dilakukan ke dalam jejak historis Git.

4. Perintah Dasar Git :

- `git init` berfungsi untuk menginisialisasi sebuah repository lokal.
- `git add .` berfungsi untuk menempatkan segala perubahan ke dalam staging area.
- `git commit -m "pesan"` berfungsi untuk Menyimpan perubahan yang telah dilakukan 
- `git status` berfungsi untuk mengidentifikasi kondisi terkini dari sebuah repositori.
- `git remote add origin URL` berfungsi untuk menghubungkan repositori lokal dengan akun GitHub.
- `git push origin main` berfungsi untuk mengirimkan modifikasi terbaru ke repositori GitHub.
- `git pull origin main` berfungsi untuk memuatkan perubahan terkini daripada repositori GitHub.

5. Praktik Workshop : Kegiatan ini mencakup pelaksanaan praktik pengembangaran proyek sederhana yang diberi nama Student Task Planner, dengan memanfaatkan HTML, CSS, serta JavaScript.

Tahapan praktik meliputi:
1. Membuat folder proyek di Visual Studio Code.
2. Membuat file HTML, CSS, dan JavaScript.
3. Menginisialisasi repository menggunakan `git init`.
4. Menggunakan arahan `git add` untuk memasukkan fail ke dalam staging area.
5. Menyimpan perubahan menggunakan `git commit`.
6. Membuat repository GitHub.
7. Menghubungkan repository lokal dengan GitHub.
8. Mengunggah proyek menggunakan `git push`.
